# Omarchy theme attribution

Main credits identify the Omarchy theme/adaptation author, not the author of its upstream palette. Credits describe initial authorship, not an exhaustive list of later contributors. Original palette sources are stored separately in `builtin-themes.json`.

The first Omarchy commits for Catppuccin, Tokyo Night, Everforest, Gruvbox, Kanagawa, Nord and Rose Pine introduce their application configs under DHH’s authorship. This is the basis for crediting DHH’s Omarchy adaptations; it does not imply authorship of their original color schemes. Explicit creator acknowledgments and existing Omarchy theme repositories take precedence over the person importing a theme.

Flexoki Light: shared Euan/DHH attribution is an inference. Euan’s earlier Omarchy port (commit ac3e391f2b6180913fe07c89b6da5496ea609764, before the built-in addition) has identical Alacritty, Hyprlock, Neovim, Waybar, Walker and SwayOSD configs to DHH’s initial bundled version. This supports preserving Euan’s contribution rather than crediting only the importer. Independently installed Git themes use their own metadata or repository owner.
